# money — 자본주의 시뮬레이터

휴대폰 화면 기준(모바일 한 칼럼, 폭 375~430px)으로 만드는 정적 사이트예요. 빌드 도구 없이 HTML·CSS·JS 파일만으로 돌아가요.
지금은 아래 탭 바와 화면 다섯 개(메시지·돈·일·무제·계정)까지 만들었어요. 메시지와 계정은 동작하고, 나머지는 자리만 있어요.

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열어요. 휴대폰으로 보려면 같은 와이파이에서 컴퓨터 주소로 들어가요.
외부 서비스에 의존하지 않아서 인터넷 연결이 없어도 돼요.

## 구조

```
index.html              화면 5개와 탭 바
app/app.css             화면과 탭 바 모양 (WebGL을 못 쓸 때의 CSS 대체 모양 포함)
app/app.js              화면 전환, 테마, 진단 스위치
app/icons.js            탭 아이콘 5개 (윤곽선 벡터)
app/backdrop.js         탭 바 뒤 화면을 사진으로 찍어 두는 곳
app/tabbar.js           탭 바: WebGL 그리기, 스프링 움직임, 터치 처리
vendor/html2canvas/     화면을 캔버스로 찍는 라이브러리 (MIT)
app/tokens.css          디자인 토큰 (Apple Store 앱 스타일)
```

## 탭 바

아이폰 26의 리퀴드 글라스 탭 바를 따라 만들었어요.

- 탭: 메시지(종이비행기), 돈(지갑), 일(톱니바퀴), 무제(?), 그리고 따로 떨어진 둥근 계정 버튼(처음에는 인스타그램 기본 프로필 같은 회색 사람 모양)
- 누르면 선택 알약이 렌즈로 떠올라요. 다른 탭을 누르면 선택된 탭에서 눌린 탭으로 미끄러져 가고, 누른 채 끌면 손가락을 따라와요.
- 이미 선택된 탭을 다시 누르면 맨 위로 올라가요. 화면마다 스크롤 위치를 기억해요.
- 라이트/다크는 기기 설정을 따라가요.

### 어떻게 그리나요

탭 바 전체(막대 유리, 아이콘, 글자, 알약, 렌즈)를 캔버스 하나에 WebGL로 직접 그려요. 버튼은 눌림과 접근성을 위해 DOM에 그대로 있고 글자만 투명해요.

**막대 유리.** 막대와 검색 버튼이 그 자체로 유리예요. 브라우저는 "지금 이 자리 뒤에 뭐가 있는지"를 픽셀로 알려주지 않아서, 화면마다 전체 길이를 한 번 사진으로 찍어 두고(`app/backdrop.js`, html2canvas) 스크롤 위치만큼 밀어서 읽어요.
이 사진을 가운데에서 확대하고, 가장자리에서는 안쪽 내용을 끌어와 휘어 보이게 하고, 글자 같은 가는 디테일은 대비를 줄여 회색으로 비치게 해요. 안쪽 가장자리의 하이라이트와 바깥의 가는 선, 그림자도 여기서 그려요.
화면 내용이 바뀌면 0.3초쯤 뒤에 다시 찍고, 탭 바를 만지는 동안에는 미뤄요. 사진이 아직 없을 때는 CSS 유리 판(`backdrop-filter`)이 대신 보이다가 사진이 오면 0.28초 동안 서서히 넘어가요.

**알약과 렌즈.** 선택 알약과 렌즈는 같은 물체예요. `lift`가 0이면 흐린 회색 알약, 1이면 맑은 렌즈이고, 누르면 떠오르고 목표까지 8px쯤 남으면 내려앉기 시작해요. 도착할 때까지 들고 있지 않아서 탭 하나를 옮기는 데 0.4초쯤 걸려요.
렌즈는 늘 막대 유리 안에 머물러요. 끝 탭에서는 폭이 알약만큼 줄고 가운데에서는 넓어지며(위치에 따라 이어서 바뀌어요), 그림자도 막대 안에만 드리워요. 끌어도 첫 탭과 검색 버튼 밖으로는 나가지 않아요.
렌즈 가장자리에서는 뒤 화면(유리)만 휘어요. 빨강·초록·파랑이 보는 자리를 다르게 줘서 하늘색·연보라·분홍·노랑 프리즘 번짐이 생기고, 가장자리를 따라 얇은 막 같은 무지개 선이 돌아요. 글자와 아이콘은 확대만 하고 휘지 않아서 글자가 아래로 흘러내리거나 테두리 밖으로 번지지 않아요.

**이동 중 막대 전체의 프리즘.** 렌즈가 떠 있는 동안(`excite`, 0.3초에 걸쳐 켜지고 꺼져요) 막대와 검색 버튼 유리 전체가 달라져요. 하얗게 덮는 정도가 줄어 뒤 화면 색이 더 비치고, 빨강과 파랑의 확대 배율이 달라져 뒤 글자에 색 번짐이 생기고, 가장자리를 따라 무지개 선이 돌아요. 이 선의 색은 렌즈 위치를 따라 흘러요.

**움직임.** 모든 움직임은 감쇠비 1(임계 감쇠) 스프링이라 되튀거나 흔들리지 않고, 프레임마다 정확한 해석해로 풀어서 프레임 간격이 들쭉날쭉해도 떨리지 않아요. 진동수(`SPRING`)가 클수록 짧게 끝나요.

### 조절 값

`new TabBar(nav, { optics, look, glass })`로 덮어쓸 수 있고, 기본값과 설명은 `app/tabbar.js`의 생성자에 있어요.

| 이름 | 하는 일 |
| --- | --- |
| `optics` | 렌즈 굴절: 가장자리 폭, 끌어오는 거리, 감쇠, 흐림, 색 번짐, 확대 |
| `look` | 렌즈 빛: 반짝임, 둘레 빛, 무지개 선, 속 밝기 |
| `glass` | 막대 유리: 가장자리 폭, 휘는 거리, 확대, 디테일을 얼마나 남길지, 알약 흐림, 이동 중 프리즘(`film`, `exciteChroma`, `exciteKeep`, `exciteWhiten`) |

색과 테마별 값(`--tab-*`)은 `app/app.css`의 `.tabbar`에 있고, 캔버스가 읽어 가요.

### 기기에서 이상하게 보일 때

주소 끝에 붙여서 원인을 가를 수 있어요.

| 주소 | 동작 |
| --- | --- |
| `?glass=off` | 뒤 화면 사진 없이 CSS 유리 판만 써요. 사진 찍기나 굴절이 문제인지 가려요. |
| `?gl=off` | WebGL을 아예 안 쓰고 DOM 아이콘과 CSS 알약으로 보여줘요. WebGL이 문제인지 가려요. |

WebGL을 못 쓰거나 셰이더 컴파일이 실패하거나 컨텍스트를 잃어도 같은 대체 화면으로 돌아가요.

### 알려진 한계

- Chromium(SwiftShader)과 WebKitGTK에서 확인했고, 실제 아이폰 사파리에서는 아직 확인하지 못했어요.
- 막대 유리는 "찍어 둔 사진"을 보여주는 거라 화면이 바뀐 직후 잠깐은 옛 모습이 비칠 수 있어요. 영상·캔버스·iframe은 사진에 안 찍혀요.
- 앱 배경이 단색이라고 가정해요. 그라디언트나 이미지 배경이면 사진에 안 찍히고 `--background` 색으로 대신해요.
- 하얀 바탕에 내용이 적으면 유리가 티 나게 굴절할 거리가 없어서 은은하게만 보여요. 글자와 색 덩어리가 지나갈 때 뚜렷해져요.

## 화면

- 스타일은 실제 Apple Store 앱(iOS 26) 화면을 따라요. 연한 회색 바탕, 모서리 28px의 큼직한 흰 카드, 굵은 큰 제목(스크롤하면 접히면서 위쪽 유리 바와 작은 제목이 나타나요), 위쪽 유리 버튼, 가로로 넘기는 카드 줄이에요. 사진 자리는 색이 번지는 면으로 대신했어요.
- 메시지: iOS 26 메시지 앱처럼 흰 바탕에 위쪽 고정 대화(큰 동그라미), 납작한 대화 목록, 검색, 읽지 않음 필터, 편집(대화 삭제)이 있어요. 대화를 열면 노을 배경에 파란 말풍선과 반투명 말풍선, 유리 버튼이 보이고 보내면 답장이 와요(예시 데이터예요).
- 계정: 기본 프로필, 게시물 0개 빈 상태, 프로필 편집(이름·소개는 이 기기에만 저장돼요). 이름을 바꾸면 기본 사람 모양 대신 첫 글자가 보여요.
- 문구는 해요체로 써요.
