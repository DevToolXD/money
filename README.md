# money — 자본주의 시뮬레이터

휴대폰 화면 기준(모바일 한 칼럼, 폭 375~430px)으로 만드는 정적 사이트예요. 빌드 도구 없이 HTML 파일 하나로 돌아가요.
지금은 아래 탭 바와 빈 화면 다섯 개까지 만들었어요.

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열어요. 휴대폰으로 보려면 같은 와이파이에서 컴퓨터 주소로 들어가요.
외부 서비스에 의존하지 않아서 인터넷 연결이 없어도 돼요.

## 구조

```
index.html          화면 5개와 탭 바
app/app.css         화면, 탭 바 모양
app/app.js          탭 이동, 렌즈 동작, 테마
vendor/liquid-glass 리퀴드 글라스 라이브러리 (MIT, 아래 참고)
design-system/      토스 스타일 디자인 시스템 (색·글자·간격 토큰, 가이드)
```

## 탭 바

아이폰 26의 리퀴드 글라스 탭 바를 따라 만들었어요.

- 탭: 메시지(종이비행기), 돈(지갑), 일(톱니바퀴), 무제(?), 그리고 따로 떨어진 둥근 검색 버튼(무제)
- 누르면 렌즈가 떠올라요. 다른 탭을 누르면 선택된 탭에서 눌린 탭으로 미끄러져 가고, 누른 채 끌면 손가락을 따라와요.
- 렌즈는 화면 전체를 비춰요. 렌즈 아래를 지나는 화면이 굴절돼 보이고, 가장자리에 빛이 갈라져요.
- 라이트/다크는 기기 설정을 따라가고, 스프링 값은 아이폰 26에서 잰 값이에요.
- 이미 선택된 탭을 다시 누르면 맨 위로 올라가요. 화면마다 스크롤 위치를 기억해요.

렌즈가 이상하게 보이는 기기에서는 주소 끝에 `?lens=bar`를 붙여 보세요. 렌즈가 탭 줄만 비추는 기본 동작으로 돌아가서, 문제가 화면 전체 복사에 있는지 가를 수 있어요.

## 디자인 규칙

- 이 스타일로 만든 화면에 토스의 이름, 로고, 앱 아이콘을 넣지 않아요.
- 문구는 해요체로 쓰고, 금융 용어는 일상 말로 바꿔 써요(`design-system/guidelines/10-writing.md`).

## 출처

리퀴드 글라스는 [dazecoop/liquid-glass](https://github.com/dazecoop/liquid-glass) 0.1.3(MIT)을 `vendor/liquid-glass`에 넣어 썼어요.
탭 바의 스프링 값과 눌림 동작이 이 라이브러리에서 왔고, 렌즈가 비추는 대상을 앱 전체로 바꾼 부분이 이 프로젝트의 것이에요.
톱니바퀴 아이콘은 첨부해 주신 이미지를 벡터로 따서 만들었어요.
